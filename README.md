# 万象画室

面向电脑浏览器的中文 AI 绘图与设计工作台。第一版提供可直接使用的本地画布编辑、项目与素材管理，并通过服务端接入 OpenAI Images API。没有密钥时仍可完整使用画布，不展示假生成结果。

界面截图：[空白工作台](docs/工作台.png) · [模板编辑](docs/模板编辑.png)

## 快速启动

需要 **Node.js 22 / 24 LTS**（最低 20.19）、npm 和现代 Chrome / Edge / Firefox。首次安装依赖需要联网。

```bash
cd /workspace/git  # 或解压后的源码目录
npm ci
npm run dev
```

浏览器打开 `http://127.0.0.1:3000`。同一 Node 服务提供前端和后端，无需分别启动。开发时前端支持 Vite 热更新；服务端文件修改后需重新启动。

正式本地运行：

```bash
npm run build
npm start
```

也可使用 `./start.sh`（macOS / Linux），或双击 `start.bat`（Windows）：首次自动安装依赖，随后构建并启动。**Windows / macOS 启动脚本未在本环境实际运行**；当前验证平台为 Linux + Node 24 + Chromium。

## 第一次使用

1. 点击「空白画布」创建项目，或选左栏模板。支持 1:1、3:4、4:3、9:16、16:9、自定义 64–4096 像素尺寸；每个图层独立可编辑。
2. 上传 PNG / JPEG / WebP（单文件最多 10MB，最多 2400 万像素，静态图片）。素材会自动转为校正方向、移除元数据的 PNG，保留透明度。可拖放文件到画布。
3. 左侧工具添加文字、矩形、圆形。拖动对象移动；拖动控制点缩放和旋转；右栏「属性」可输入精确数值、对齐画布、复制、删除、调整层级。
4. 文字支持字体、字号、颜色、字重、对齐和行距。图像支持裁剪（原图像素坐标）、旋转、翻转、透明度、亮度、对比度。「图层」中可显示/隐藏、锁定/解锁和调整画布尺寸。
5. 顶部项目名可直接重命名。点击「保存」或 Ctrl/Cmd+S；保存至服务器，刷新自动恢复上次保存的项目。「项目」中打开、重命名、删除其他项目。**未保存内容不会自动持久化**，离开时会提示。当前编辑会话保留最多 80 步撤销，重新打开项目后重新开始撤销记录。
6. 导出 PNG / JPEG，按画布原始尺寸输出，不受当前缩放和平移影响。透明 PNG 选项只移除画布背景，不移除独立背景色块/图片图层。JPEG 用画布背景填充，透明画布用白底。

快捷键：Ctrl/Cmd+Z 撤销；Ctrl/Cmd+Shift+Z 或 Ctrl/Cmd+Y 重做；Ctrl/Cmd+D 复制；Delete 删除；空格+拖动平移；Ctrl/Cmd+滚轮缩放。文字输入时保留输入框自己的快捷键行为。

## AI 服务配置

右上角设置图标，或右侧「配置 AI 服务」进入设置，填写：

- 服务适配器：OpenAI Images API。
- 地址：默认 `https://api.openai.com/v1`。
- 模型：`gpt-image-1`、`gpt-image-1-mini`、`gpt-image-1.5` 中选一个，需你的账号具有相应模型权限。
- 密钥：真实服务商 API 密钥。仅保存在服务器私有 `.data/config.json` 中（POSIX 文件权限 600），不回传、不写入浏览器存储、项目文件或应用日志。它是文件存储，并非加密密钥库；请保护服务器及备份。

也可复制 `.env.example` 为 `.env`，设置 `WANXIANG_AI_KEY`（或现有 `OPENAI_API_KEY`）、`OPENAI_BASE_URL` 后重启。服务端优先复用这些环境变量。环境变量密钥启用时，地址切换与密钥清除必须在服务器环境中进行。

后端支持现有 `HTTPS_PROXY` / `HTTP_PROXY` / `NO_PROXY` 企业代理，保留 TLS 证书校验。网络策略须允许 `api.openai.com`；官方固定地址不依赖本机 DNS 解析。

仅支持与文档一致的 OpenAI Images API 协议；自定义 HTTPS 地址由用户自行确认协议兼容，**未宣称其他服务商已兼容或已验证**。禁止本机、内网、非 HTTPS 等地址；自定义 IPv6 目标暂不支持。切换服务地址必须重新输入凭证，防止意外将原有密钥发送至新目标。

### 生成流程

- 文字生图：填写中文描述，选择风格、尺寸、数量、质量，点击「开始生成」。风格由本地规则追加到提示词，真实提交的提示词可在历史查看。
- 参考图生成：上传原图或使用画布选中的图片素材，再输入修改说明。当前模型未提供「参考强度」接口，所以不显示此参数。
- 局部修改：选择原图，点击「涂抹局部修改区域」，用画笔/擦除工具编辑选区并确认，再填写指令。使用原始素材，不含画布上的裁剪、滤镜或文字。**后端同时发送原图、PNG 遮罩及指令**；遮罩透明区域是待修改区域，未选区域不透明。模型尽量保留未选区域，不能保证像素级一致。
- 生成尺寸按这三个模型的已实现能力提供 1024×1024、1024×1536、1536×1024。它与设计画布比例相互独立；可把结果放入其他比例画布，自行裁剪排版。
- 数量 1–4，质量 low / medium / high，输出 PNG。任务状态包含等待、生成中、完成、失败。结果可预览、下载、加入画布。
- 历史保留提示词、实际参数、模型、原图/遮罩引用、状态与结果。复用只填回参数，仍需再次点击生成；**不自动重试收费请求**。超时或服务重启中断可能已经计费，应先检查服务商记录。
- 提示词助手是**本地结构化表单**，不调用额外 AI；可查看并修改主体、数量、构图、背景、色彩、材质、光线、风格及限制条件，确认后再生成。空白内容不臆造。

## 架构与数据

```text
client/src/
  main.jsx          三栏工作台、项目与素材交互、任务历史
  editor.js         Fabric.js 图层、坐标变换、撤销重做、导出
  Properties.jsx    对象属性、文字与图像处理
  MaskEditor.jsx    原图遮罩绘制、擦除、预览与 PNG 输出
  Dialogs.jsx       新建、服务设置、提示词助手
  templates.js      六种可编辑模板、比例预设
server/
  index.js          API、会话、设置、项目与品牌接口、前端托管
  store.js          原子 JSON 文件持久化
  assets.js         图片解码、归一化、限制与遮罩校验
  ai.js             独立能力注册表及 OpenAI Images 适配器
  tasks.js          持久化任务队列、状态流转、幂等与中断恢复
```

React 19 + Fabric.js 6 + Vite 7；Express 5 + Zod + Sharp；Node 内置测试运行器 + Playwright。

项目 `schemaVersion: 1`，保存画布宽高/背景、Fabric 对象列表、素材 UUID、平移/缩放及选中图层。对象 `id`、`label`、`assetId`、`locked` 与图片调节参数参与序列化。对象坐标为未缩放的画布像素；视图缩放只影响显示。素材用同源 `/api/assets/:uuid` 引用，项目不内嵌服务凭证或外部图片地址。导出使用同一个 Fabric 渲染引擎在独立原尺寸画布重放内容。

`.data/` 下保存素材 PNG、项目、品牌库、生成历史与服务配置。它已被 Git 忽略。备份时完整备份该目录，并保护其中的密钥和私有图片；首次正式版本不包含素材回收站或自动垃圾清理。删除项目不删除素材。不要多个 Node 进程同时使用同一数据目录。

## 私有访问与部署

默认绑定 127.0.0.1，是**单人本地工作室**，不是多租户云服务。素材、任务、设置和项目接口均要求 HttpOnly / SameSite=Strict 会话 Cookie；写接口还检查自定义请求头与同源 Origin；上传只接受受限、可解码的静态图片；图片和遮罩均有尺寸校验。公开静态目录不包含私有数据。

需要局域网/服务器访问时，在 `.env` 设置 `HOST=0.0.0.0`、强 `WANXIANG_PASSWORD`，并在正式部署中使用 HTTPS 反向代理。未设密码时禁止对外监听。不要将开发服务或 `.data` 目录直接公开到互联网。会话 24 小时过期，重启后需重新登录。第一版没有用户账号、分用户权限或协作隔离，掌握工作室密码的用户共享同一工作室。

## 测试

```bash
npm test
npm run build
# 已安装 Chromium 时自动使用 /usr/bin/chromium；也可设置 CHROMIUM_PATH
# 其他机器首次运行浏览器测试：
npx playwright install chromium
npm run test:e2e
```

浏览器测试会另启 3173 端口、在系统临时目录创建独立数据，不访问真实 AI，不使用生产密钥。自动化测试会禁用 `.env` 加载并清空子进程 AI 凭证，不使用真实密钥或调用付费服务。后端适配器契约测试明确使用测试替身，只验证请求内容与错误处理，**不能证明真实服务生成可用**。详细结果见 [验收记录](docs/VALIDATION.md)。
