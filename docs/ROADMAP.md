# 分阶段扩展计划

第一版优先交付可靠的本地设计、存储、导出和 AI 请求链路。下列内容未实现，界面不提供可用按钮；阶段验收通过后再进入下一阶段。

## 第二阶段：产品图片处理

先评估有正式文档、可合法使用的抠图服务或本地模型，接入智能抠图、独立背景图层与背景替换。验收重点是透明边缘、发丝/半透明材质、原产品不被重绘、素材来源可追溯。随后依据真实工具能力接入扩图、修复、放大，记录输出尺寸与费用。

## 第三阶段：创作效率

手绘笔刷与 Pointer Events 压感（在支持的硬件验证）、多画板、批量导出、同一商品多尺寸布局。先建立画板坐标模型和布局约束，再做批处理；导出需验证字体、裁剪与各尺寸一致性。

## 第四阶段：一致性参考

人物和系列图片参考集、产品多视图、已确认角色特征与限制条件。参考能力依据服务官方参数落地，保留来源和实际参数；不承诺模型无法保证的人脸/产品像素一致。

## 第五阶段：云端工作室

账号、加密凭证库、数据库/对象存储、按用户和团队授权、云端项目版本、多租户任务队列与审计、协作编辑。应先迁移单人文件存储与会话模式，再部署公网服务，不把第一版密码共享模式当作多租户权限系统。
