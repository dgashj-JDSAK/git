## 当前环境的真实服务探测

官方 OpenAPI YAML 已从 OpenAI 官方 GitHub 仓库成功读取。开发者指南网页在本环境返回 403，采用官方 OpenAPI 作为依据。

本机直接解析 `api.openai.com` 曾返回 `EAI_AGAIN`，通过环境代理的无凭证 HEAD 探测返回 HTTP 403。适配器现支持 `HTTPS_PROXY` / `HTTP_PROXY` / `NO_PROXY`，官方固定域名可由代理解析；配置校验已通过，但没有进行带密钥的生成调用。不能将配置保存、网络探测或模拟请求称为真实 AI 可用。

真实验收需在拥有可访问网络、模型权限及余额的环境，由用户通过服务设置或服务器环境变量安全提供密钥，再手动提交一次生成和局部修改。不要在聊天里发送密钥；请求可能收费，失败/超时不自动重试。
